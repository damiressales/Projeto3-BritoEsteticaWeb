# Brito Estética Automotiva — Portal Web

Aplicação web voltada aos clientes da **Brito Estética Automotiva**, permitindo conhecer os serviços oferecidos, consultar valores e realizar agendamentos online de forma prática e responsiva.

## Funcionalidades
- **Catálogo de Serviços:** Exibição detalhada dos procedimentos automotivos organizados por categoria.
- **Agendamento Online:** Fluxo intuitivo para escolha de serviço, data e horário disponíveis.
- **Área do Cliente:** Cadastro, autenticação e acompanhamento dos agendamentos realizados.
- **Interface Responsiva:** Layout estruturado em HTML5 e CSS3 adaptado para dispositivos móveis e desktop.

## Tecnologias Utilizadas
- **Front-end:** TypeScript, HTML5, CSS3
- **Back-end / Integração:** PHP
- **Banco de Dados:** MySQL
